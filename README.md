# Fraud Transaction Analysis

## Project Overview
This project analyzes financial transaction data to identify fraudulent activities using Excel, SQL, Python, and Power BI.

## Tools Used
- Microsoft Excel
- SQL
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Power BI

## Dataset Features
- Transaction Amount
- Transaction Time
- Location
- Device Type
- Merchant ID
- Card Holder Age
- Fraud Status

## Project Workflow
1. Data Cleaning using Excel
2. Exploratory Data Analysis using Python
3. SQL Query Analysis
4. Dashboard Creation using Power BI
5. Business Insights and Recommendations

## Key Insights
- High transaction amounts have a higher probability of fraud.
- Device type influences transaction behavior.
- Certain locations show increased fraud risk.
- Card holder age also affects transaction patterns.

## Business Recommendations
- Monitor high-value transactions.
- Add extra verification for risky transactions.
- Track unusual device and location activity.
